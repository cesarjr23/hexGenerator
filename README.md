# Gerador Hexadecimal

Aplicação web desenvolvida com **HTML, CSS e JavaScript** que permite selecionar cores, visualizar seus códigos hexadecimais e acompanhar as alterações em tempo real.

O projeto foi desenvolvido como exercício prático de manipulação do DOM, eventos e estilização dinâmica de elementos HTML.

---

## Demonstração do projeto

![Gerador Hexadecimal em funcionamento](./preview.png)

*A interface permite selecionar uma cor e visualizar automaticamente seu código hexadecimal e a alteração da cor do título.*

## Funcionalidades

- Seleção de cores por meio de um seletor interativo.
- Exibição automática do código hexadecimal da cor escolhida.
- Atualização da cor do título em tempo real.
- Interface estilizada com CSS.
- Funcionamento diretamente no navegador, sem necessidade de instalação de dependências.

---

## Como executar

1. Baixe os arquivos do repositório ou clone o projeto.
2. Mantenha os arquivos `index.html`, `style.css` e `index.js` na mesma pasta.
3. Abra o arquivo `index.html` em seu navegador.
4. Utilize o seletor de cores para visualizar as alterações.

---

## Conceitos aplicados

- Estruturação de páginas com HTML5.
- Estilização e organização visual com CSS3.
- Manipulação do DOM utilizando JavaScript.
- Captura de eventos com `addEventListener`.
- Atualização dinâmica de propriedades CSS.
- Utilização de códigos hexadecimais para representação de cores.
